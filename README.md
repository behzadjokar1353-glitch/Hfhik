# حسابداری بهزاد — نسخه توسعه‌یافته سورس اندروید

رابط فارسی راست‌چین برای حسابداری شخصی و فروشگاهی.

## امکانات سورس این نسخه
- انتخاب واحد پول تومان/ریال
- داشبورد، سوابق و گزارش خلاصه
- ثبت فاکتور فروش و خرید چندقلمی
- چاپ فاکتور با سرویس چاپ اندروید
- تعریف، ویرایش و حذف کالا با کد کالا/بارکد
- اسکن بارکد با Google Code Scanner (نیازمند Google Play services؛ اسکنر در دستگاه‌های پشتیبانی‌شده)
- کنترل موجودی فروش در برابر موجودی قابل‌فروش
- ورود و خروج دستی موجودی
- مدیریت مشتریان و تأمین‌کنندگان
- تعریف صندوق، حساب بانکی و مانده اولیه
- ثبت بدهی/طلب و علامت‌گذاری تسویه
- ثبت درآمد و هزینه
- ذخیره فایل پشتیبان JSON با انتخاب محل ذخیره
- بازیابی فایل پشتیبان JSON با تأیید جایگزینی اطلاعات
- محاسبه برآوردی سود ناخالص و خالص از بهای خرید ثبت‌شده در کالا

## محدودیت‌های مهم
این هنوز نسخه اولیه توسعه‌پذیر است و حسابداری رسمی/دوطرفه کامل نیست. سود خالص برآوردی است و به روش بهایابی، تخفیف‌ها، مرجوعی، مالیات و هزینه‌های مستقیم وابسته است. عملیات چندکاربره و همگام‌سازی ابری، گزارش‌های رسمی دفتر کل/ترازنامه، مجوزهای نقش‌محور و آزمون‌های کامل هنوز پیاده‌سازی نشده‌اند. برای بارکد، کد باید از قبل در کارت کالا ذخیره شده باشد.

## ساخت APK
1. Android Studio را نصب و پروژه را باز کنید.
2. Android SDK Platform 35 را نصب کنید.
3. Gradle Sync را کامل کنید (اتصال اینترنت برای دریافت وابستگی اسکن بارکد لازم است).
4. Build > Build APK(s) را اجرا کنید.
5. APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

پروژه از Android Gradle Plugin 8.7.3 و Kotlin 2.0.21 استفاده می‌کند. این محیط Android SDK و Gradle نصب‌شده ندارد؛ در نتیجه APK واقعی در این محیط کامپایل یا آزمایش نشده است.


## خروجی Excel و PDF (نسخه ۱.۲)

در صفحه «تنظیمات» و «گزارش‌ها» می‌توانید:
- فایل Excel با پسوند `.xlsx` بسازید. فایل چند برگه دارد: تراکنش‌ها، کالاها، ریز فاکتورها، اشخاص، بدهی‌ها و حساب‌ها.
- گزارش PDF شامل خلاصه مالی، سوابق تراکنش‌ها، ریز اقلام فاکتورها و فهرست کالاها تولید کنید.
- هنگام ذخیره، محل و نام فایل را در پنجره استاندارد اندروید انتخاب کنید؛ پس از ذخیره نیز دکمه اشتراک‌گذاری فایل در دسترس است.

فایل‌های خروجی به صورت محلی تولید می‌شوند. گزارش سود و زیان همچنان برآوردی است و جایگزین بررسی حسابدار نیست.


## ساخت APK خودکار با GitHub Actions

این پروژه شامل workflow در مسیر `.github/workflows/android.yml` است. برای دریافت APK:
1. ZIP سورس را روی رایانه استخراج کنید.
2. کل پوشه پروژه را در یک مخزن GitHub جدید آپلود کنید.
3. در بخش **Actions**، اجرای **Build Android APK** را باز کنید و در صورت نیاز **Run workflow** را بزنید.
4. پس از موفقیت ساخت، بخش **Artifacts** را باز کنید و `hesabdari-behzad-debug-apk` را دانلود کنید.
5. فایل ZIP دانلودشده از Artifacts را استخراج کنید تا `app-debug.apk` به دست آید.

این روش به دسترسی اینترنت در GitHub و موفقیت build وابسته است. APK تا پیش از اجرای موفق workflow ساخته‌شده محسوب نمی‌شود.
